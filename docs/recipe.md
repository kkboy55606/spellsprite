# 配方格式 `pfx/1`（凍結契約）

每個特效都是一份 JSON 配方。引擎（`src/core/engine.js`）讀配方、輸出 RGBA 影格。
這份格式是**凍結契約**：之後只能 additive（新增欄位要有預設值、新增圖層種類），
不得改名、刪除或改變既有欄位的意義，否則舊的分享連結與存檔會壞掉。

未知欄位會被保留但忽略，所以可以在配方裡放筆記。

## 座標與時間

- 單位：1 單位 = 畫布短邊的一半。`x`、`y` 從畫布中心算，y 向下為正。
- 時間：單次特效從 0 跑到 1（最後一幀 = 1）；循環特效的相位 0 到 1 首尾相接。
- 圖層的 `from`、`to` 決定它在特效中的哪一段播放（只對單次特效有效）。
- 熱度約 1 = 色帶最亮色，接近 `cut` = 最暗色，低於 `cut` = 透明。
